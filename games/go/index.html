// faq

Questions, answered directionally.

Is h4ks go an agent?

No. It was very briefly described as one and that was wrong. It is a provider — the subscription your agent connects to. The agent is yaa. The provider is us. The arrow points down.

What's first-class support for yaa?

yaa works with h4ks go out of the box: official config, tested on every model, and a support channel that answers in agent rather than human. Other agents still work — they're just economy class.

Is this opencode zen?

It is opencode-zen-shaped but h4ks. Same idea: agent and provider are separate products that you should be able to mix and match. We just did the provider part, with more acid green.

Can I use my go key with opencode?

Yes — OpenAI-compatible endpoint, drop it into opencode's provider config and go. Loyalty to one agent is a choice, not a requirement.
