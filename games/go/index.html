★ FIRST-CLASS SUPPORT

Speaks fluent YAA.

https://yaa.games.h4ks.com

Yet Another Agent isn't a bolt-on integration — it's a peer. h4ks go treats YAA as a first-class provider: one connect command, shared sandbox, shared memory, routed together.

  • ✓Provider, not plugin. yaa appears in your model router like any other provider. Pick it, or let YAA route itself.
  • ✓Agent-to-agent. h4ks go plans, YAA executes tool calls in its sandbox — or the other way round. They argue. You win.
  • ✓Shared memory. Context learned on one side is context known on the other.
  • ✓Game platform hooks. Ships things to games.h4ks.com straight from a session.

// FAQ

Fair questions.

What is h4ks go?

An open AI coding agent — like opencode, but it's h4ks. It writes code in your terminal, IDE, browser, or IRC channel, and routes work to any model you point it at.

Do I need YAA to use h4ks go?

No. YAA (yaa.games.h4ks.com) is one provider among many. It's just first-class — meaning h4ks go connect yaa is one command, and the two agents interoperate deeply instead of merely politely.

Can I use it from IRC?

That's half the point. opencode run is headless and opencode serve exposes HTTP — a 30-line bot plugin turns any channel into an agent queue.

Is my code private?

h4ks go stores nothing. Your code and context stay on your machine — or on the machines you explicitly connect. Privacy-sensitive environments welcome.

Why is it called "go"?

Because it goes. Also because "h4ks free, h4ks go, h4ks pro" was said out loud once and became product strategy within the hour.

What about Token Burner mode?

It exists. It burns tokens. There is a song about it. Use responsibly, or don't — the quota is your problem.
