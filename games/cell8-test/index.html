Cell-8: hexagonal CA with a wildcard input cell (sketch)

Input stream (text, sent as bits into the wildcard cells on row 0):
Genome: 28 bits, one per (self, live neighbours 0-6, wildcard). Click to toggle. Column labels: index = self*14 + neighbours*2 + wildcard.
Each step, every hex cell looks at itself, its 6 hex neighbours and a wildcard bit. Row 0 receives the current input bit; other rows get 0. The genome table decides the next state. The grid wraps on a torus. This is only a sketch of the idea, not a trained system.
