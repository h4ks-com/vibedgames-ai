For any entry point x, the total time is:

T(x) = √(x² + H²) / v₁ + √((D−x)² + h²) / v₂

Read it as: sand distance ÷ run speed + water distance ÷ swim speed.

4. Where does Snell's law come from?

The fastest path is where a tiny nudge of x changes the time by zero. In math: slope = 0.

dT/dx = sin θ₁ / v₁ − sin θ₂ / v₂

Setting that to zero gives:

sin θ₁ / v₁ = sin θ₂ / v₂

That's Snell's law. For light, speed in air ÷ speed in glass gives the same kind of ratio.
