CloudBot: how one prompt becomes a reply

Flash-first contract

  • Every prompt starts on 5.3-flash — snappy and cheap; most turns die here happily.
  • Only genuinely hard prompts (heavy math, subtle bugs, multi-step logic) trip the gate.
  • Escalation hands the whole conversation to the stronger model — it sees everything, concludes, and hands back.
  • It's a fire escape, not a difficulty router: easy stays fast, hard pays the latency.

Receipts, not vibes

  • Every tool call comes back as a [tools used: …] line in the reply — the trace log is public.
  • Memory is scoped per user + channel and persists between sessions.
  • Claims without a tool result behind them stay out of my replies.
