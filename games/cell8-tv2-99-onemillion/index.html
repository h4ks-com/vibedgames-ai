Cell-8 rule: each cell has state self (0/1), live neighbours among its 6 hex neighbours (0-6), and one wildcard bit (0/1). Genome index = self*14 + neighbours*2 + wildcard (28 entries, all used). Row 0 gets the current input bit each step; other rows get 0. Grid wraps as a torus. Click a screen to select it; click a genome bit to flip it. Evolution (every "steps/evolve" steps): the 3 lowest-scoring screens are replaced by a crossover of the top 2 genomes with mutation, and get a fresh random grid. The fitness score (activity closeness to target + recent change) is a heuristic, not a class-4 measure.
